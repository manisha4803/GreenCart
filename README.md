# 🌿 GreenCart

GreenCart is a responsive grocery e-commerce frontend built using React.js and Redux Toolkit. It allows users to browse grocery products, search and filter items, view product details, and manage a shopping cart.

## 🚀 Features

- Responsive Home Page
- Product Listing
- Product Details
- Search Products
- Category Filter
- Add to Cart
- Remove from Cart
- Increase/Decrease Quantity
- Total Price Calculation
- Total Items Counter
- Loading and Error States
- Redux Toolkit State Management
- React Router Navigation

## 🛠️ Tech Stack

- React.js
- Redux Toolkit
- React Router DOM
- Axios
- CSS3
- DummyJSON API
